\section{拟采用的模型、算法或系统方案}

\textbf{总体架构与任务编排。}
结合第二节的分层思路，考虑到任务指令仅包含颜色与体积、操作顺序相对固定，本项目拟首先验证状态机、VLA 与专用倾倒控制器相结合的方案。
状态机读取指令 $u=(c,V^\star)$，按定位、抓取、转运、对准、倾倒和归位的顺序调用技能，并以模板生成含目标颜色等参数的 VLA 子任务描述。
状态转换依据图像与机器人状态判断，抓稳后才转运、瓶口对准且液量读数可靠后才倾倒。
识别不确定或抓取失败时返回观察、有限次重试，超时或连续失败则暂停并记录原因。

\textbf{感知、抓取与转运。}
拟利用相机识别目标颜色的瓶子，并结合可用深度信息估计其位置。
VLA 接收当前图像、子任务描述及模型所需的机器人状态，生成抓取、对准和归位等短时动作，经坐标与动作维度适配、限位及速度检查后，通过 SDK 执行。
固定场地中的底盘移动拟采用预标定工作位与导航接口，到位后用视觉修正瓶子和量筒的相对位置。
主操作臂承担抓瓶和倾倒，另一臂按需辅助。抓瓶后通过小幅抬升及视觉复核确认持瓶状态；进入倾倒状态时结束 VLA 动作执行，由倾倒模块接管机械臂。
先验证 SDK 观测与动作接口，再逐项测量预训练 VLA 的抓取、对准和归位成功率，必要时采集短技能示教数据进行适配。

\textbf{视觉反馈定量倾倒。}
初版拟采用分次倾倒与稳定读数闭环。固定读数视角，标定量筒刻度与图像位置的对应关系，检测凹液面下缘并估计体积 $\hat V$，以连续多帧读数的稳定性检查估计是否可靠。
控制器根据剩余量 $e=V^\star-\hat V$ 选择倾角、倾斜速度和保持时间；远离目标时采用较大单次倾倒量，接近目标时切换为短时、小流量补倒。
每次倾倒后回正，待余流进入量筒且液面稳定后重新读数。根据夹爪至瓶口的相对位置同步补偿末端平移，使倾倒过程中的瓶口保持对准量筒。
回正提前量由不同瓶内剩余液量下的试倒数据标定；若读数失效则回正暂停，若已超量则停止并记录误差。
停止容差需在 $5\%$ 的评分目标内为测量误差预留余量。首次实验将测定视觉读数误差、最小可控倾倒量及回正余流，据此确定粗细阶段切换阈值和动作参数。
各模块验证后接入状态机进行完整流程测试，记录状态转换失败原因及最终体积误差。以上为拟实施方案，尚待真机验证。
