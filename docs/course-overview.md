# 课程大作业说明

## 一、总体要求

本课程**不设笔试**。课程大作业设置四足机器人、机械臂（桌面双臂）和轮式双臂三个赛道，**每组选择并完成其中一个赛道**。

大作业以探索与创新为主，不以性能打榜为唯一目标。各组应围绕所选任务，完成技术方案设计、实验验证与结果分析，并清楚说明采用的方法、取得的结果和存在的局限。

**机器人实验室地点：学生中心 D313。**

## 二、大作业赛道与任务概览

| 赛道 | 实验平台 | 核心任务 | 技术要求与配套资源 |
| --- | --- | --- | --- |
| 四足机器人 | ZSL-1 四足机器人 | 操作员遥控机器人完成地形赛道往返。赛道包含平地、泡沫地垫、障碍块、软垫、斜坡和台阶；测试过程中，任何一只脚均不得越出赛道边界。 | 训练或改进运动策略，并部署到真机；操作员通过遥控器给出速度指令。提供部署管线 `zsl_deploy` 和训练框架 `robot_lab`。 |
| 机械臂（固定双臂） | 桌面双臂系统  | 从两个托盘中取出金属颗粒与块料，按给定质量配比完成称量和调整，最终在成品托盘中交付总质量 20 g 的材料；同时核验两种材料的分项质量与总质量。 | 技术路线开放，可采用 VLA、WAM、智能体、传统规划或外部大模型等。`wall-x` 可作为模型参考；原单臂数采管线 `zbl_arm_6a_datacol` 保留作参考，双臂接口按实际设备适配。**如果选择智能体方案，自变量机器人将提供最新的具身模型token支持，通用大模型需自费（化缘ing）。** |
| 轮式移动双臂 | 量子一号 Pro 轮式双臂机器人 | 根据指令选取指定颜色的瓶子，向量筒中倒入指定体积的液体。 | 技术路线开放，可采用 VLA、WAM、智能体、传统规划或外部大模型等。提供量子一号配套开源全链路框架 `wall-x`。 **建议选择智能体方案，自变量机器人将提供最新的具身模型token支持，通用大模型需自费（化缘ing）。** |

各赛道的详细任务、器材配置、测试规则、评分标准和资源使用方法，以对应文件夹中的大作业要求文档为准。

**特别说明 2： 自变量机器人将提供部分训练资源（有限卡数、有限固定时间）支持，建议有训练资源的学生优先选择基于训练的大作业。**

**特别说明 3： 所有给定核心任务为基础必做任务，学有余力者鼓励进行更复杂、更有意思的任务探索。**

## 三、阶段要求与时间安排

三个赛道共用同一时间线。

| 时间 | 安排与要求 |
| --- | --- |
| W5 | 发布大作业题目及要求 |
| W6 | 完成大作业宣讲与答疑 |
| W7 | 完成组队与赛道分配 |
| W10周四23:59:59前 | 提交不超过4页的中期报告 |
| W16周二23:59:59前 | 完成最终真机测试，并在 Canvas 提交全部材料 |
| W16 | 完成答辩展示 |

### 中期报告

每组提交一份**不超过4页的中期报告**，建议包含：

- 研究问题、任务目标与评价方式；
- 相关工作；
- 拟采用的模型、算法或系统方案（简单叙述，不作为中期考核的重点）；
- 已完成的工作与初步实验结果；
- 当前困难、后续计划及组内分工。

### 最终报告与配套材料

每组提交一篇**至少4页的 mini paper**。

**报告字数不作为评分指标。** 报告应以清楚、准确和有实验依据为原则，避免为增加篇幅堆砌内容。

### 答辩展示

答辩安排在**第16周**。各组应展示大作业的研究问题、采用的模型或方法、实验结果，并播放**视频 Demo**，说明系统的实际运行效果、成功情况和失败案例。

**视频 Demo 是重要考核材料，须随最终材料一并提交。**

## 四、评分说明
- **中期报告30%**，**Mini paper（详细计分见每个赛道大作业要求.md中计分方法部分）30%**，**答辩展示30%（视频demo占20%，presentation 10%）**、**出勤10%**。
- 各赛道具体分项以对应的大作业要求文档为准。

## 五、真机实验与设备使用

- **实验地点：学生中心 D313 机器人实验室。**
- 每组前3次真机尝试，必须由助教**费文博或者唐扬在场陪同**。
- 完成前3次陪同实验后，可联系助教**金恒柘**预约实验时段及开门。
- 真机实验须遵守对应平台的安全操作与设备管理规定；机械臂外借按获批设备的适用规定执行。
- 各组应提前安排训练、调试与测试时间，并在截止时间前完成最终真机测试。

## 六、组队与志愿填报

### 组队

- **3～4人一组**，自由组队。
- 各组先在腾讯文档中登记组员信息，再按课程组通知填报赛道志愿。

### 志愿填报与分配

- 每组填写三个赛道的意向排序，即第一、第二、第三志愿。
- 问卷于**10月29日12:00截止**。
- **三个选题均不设置组数上限，每个选题至少安排 2 组。**
- 按问卷提交时间先后依次处理，优先满足第一志愿；为保证每个选题至少 2 组，必要时结合第二、第三志愿统筹调整。

## 七、作业提交

各组将全部材料整理打包，在 Canvas 上以小组形式提交。最终材料包括：

- 最终 mini paper；
- 代码及运行说明；
- 实验数据、结果记录及相关附件；
- 视频 Demo。

具体文件格式、命名要求及补充材料，以所选赛道的大作业要求文档为准。

**最终真机测试与作业材料提交截止时间：W16周二23:59:59。**
