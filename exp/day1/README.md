# 第一次真机实验（2026-11-22）· 操作手册

> 目标（对应 W11 计划）：**SDK 接口验证 + 相机与量筒刻度标定 + 感知模块离线数据采集**。
> 首次真机必须有助教（费文博/唐扬）在场陪同，提前一天确认好时间。

## 目录

| 文件 | 用途 |
| --- | --- |
| `setup_env.sh` | 一键创建虚拟环境并安装 SDK |
| `00_check_connect.py` | SDK 连通性检查（第一天第一件事） |
| `01_dump_state.py` | 全量状态导出（关节角/位姿/电量/IMU…） |
| `02_capture_cameras.py` | 所有相机连拍存盘（带回去做离线感知开发） |
| `03_smoke_test.py` | 交互式冒烟测试（每步确认，小幅动作验证各执行器 API） |
| `04_cylinder_calib_capture.py` | 引导式量筒刻度标定采图（感知模块的命根子） |
| `05_measurements.md` | 现场测量记录表（打印带去） |
| `06_questions_for_ta.md` | 问助教的问题清单 |
| `KNOWLEDGE.md` | 背景知识速成（具身智能/VLA/SDK/坐标/安全） |

## 行前准备（11-20、11-21 完成）

1. **下载 SDK**（两版都带上）：
   - `x2robot-1.1.2-py3-none-any.whl`（纯 Python，Windows/WSL 都能装，43 KB）
   - `x2robot_sdk-2.0.0-cp310-cp310-manylinux_2_35_x86_64.whl`（新版，仅 Ubuntu）
   - 地址：https://github.com/X-Square-Robot/sdk_robot/releases
   - 现场问助教机器人固件版本对应哪版 SDK；先用 v2.0.0（Ubuntu），不行换 v1.1.2。
2. **装环境**（在**自己带去实验室的笔记本**上跑，不是机器人上——机器人自带 SDK 服务，无需安装）：
   ```bash
   cd exp/day1
   bash setup_env.sh /path/to/x2robot_sdk-2.0.0-cp310-cp310-manylinux_2_35_x86_64.whl
   ```
   - 脚本优先用 `uv`（自动装 Python 3.12），没有则退回 `python3 -m venv`；谁要跑脚本谁装一份。
   - v1.1.2 固定 `numpy==1.26.4`，Python 最高 3.12；默认 3.12 两个 wheel 版本都兼容。
   - v1.1.2 是 `py3-none-any`，**Windows 原生 Python 也能装**——若 WSL 网络连不上机器人，这是后备方案（v2.0.0 仅 Linux）。
3. **物品清单**：
   - 笔记本电脑（充满电）+ 充电器
   - **网线 + USB 转 RJ45 转接头**（机器人有线口固定 `192.168.10.1:50051`，无线不通时的救命方案）
   - 卷尺（测桌子/瓶子/托盘）、手机（拍全景与刻度特写）
   - 打印 `05_measurements.md` 和 `06_questions_for_ta.md`
   - 一个带刻度的量杯（家里量米/烘焙那种即可，标定加水时用）
   - 急停负责人提前指定：实验期间**一人专职守着急停按钮**
4. 用 `--help` 把 4 个脚本各跑一遍，确认无 SDK 也能打印帮助（脚本是惰性导入 SDK 的）。

## 当天流程（约 3 小时，按优先级，时间不够就砍后面的）

### 阶段 0：开机与场地测绘（0:00–0:30）

1. 检查机身急停按钮处于松开状态；长按电源键 3 秒开机，等 2–3 分钟听到"咔嚓"声。
2. **等开机的间隙做场地测绘**（填 `05_measurements.md`）：桌子长宽高、两个托盘相对桌边的位置、4 个瓶子的高度/直径/瓶口直径、量筒量程与刻度间距、颜色对应关系。手机拍照留档。
3. 规划机器人停放位：正对桌子、与托盘 A/B 都保持一条臂能舒服够到的距离（臂展 649 mm，桌面操作高度注意臂的工作空间）。

### 阶段 1：网络与 SDK 连通（0:30–1:00）★最高优先级

1. 问助教：机器人现在的 IP？实验室 WiFi 的 SSID/密码？（或借显示器看机器人桌面 `http://localhost/` 的 Web UI）
2. SSH 验证：`ssh xr@<机器人IP>`（密码 `123`；Windows 用 `ssh.exe`）。
3. 跑连通检查：
   ```bash
   .venv/bin/python 00_check_connect.py --server <机器人IP>:50051
   ```
   预期输出 `ping 响应: Pong to: Hello, X2Robot!` 和电量信息。
4. 不通的排查顺序：`ping <IP>` → 问助教端口是否 50051 → 网线直连方案（笔记本设 `192.168.10.10/24`，机器人有线口 `192.168.10.1`）→ 求助教。

### 阶段 2：状态导出与相机采图（1:00–1:30）★最高优先级

```bash
.venv/bin/python 01_dump_state.py --server <IP>:50051
.venv/bin/python 02_capture_cameras.py --server <IP>:50051 --frames 5
```

- 相机画面里必须拍到**真实场地**：托盘、4 个瓶子、量筒。这组照片是感知组离线开发的全部素材。
- 拍完当场用 `cv2.imwrite` 检查一遍能不能打开（脚本已自动保存到 `data/cameras/<时间戳>/`）。
- 顺带把每个相机画面在屏幕上过一眼，记下：哪些相机能看清托盘 A、哪些能看清量筒（填进 05 表格）。

### 阶段 3：冒烟测试（1:30–2:00）

```bash
.venv/bin/python 03_smoke_test.py --server <IP>:50051
```

脚本按「夹爪 → 腰身 → 头部 → 机械臂 → 底盘」顺序逐项小幅动作，**每步回车确认**。这一步的意义：
- 验证每个 API 的语义：单位（弧度/米/度）、正负方向、限位。
- 感受各执行器的运动速度和噪声水平。
- 机械臂动作前请助教确认姿态安全；底盘移动前清空周边。

### 阶段 4：量筒标定采图（2:00–2:30）★感知组命根子

```bash
.venv/bin/python 04_cylinder_calib_capture.py --server <IP>:50051 --levels 0,25,50,75,100
```

脚本引导：把量筒放托盘 B → 加水到指定刻度 → 回车 → 自动从头部相机（彩色+深度）和双腕相机各拍一张，**同时记录当前底盘里程计**（离线标定必须知道拍照时机器人站在哪）。液位档位按量筒实际量程现场改。
- 机器人位置全程不动；量筒位置每次摆放尽量一致（可用胶带做标记）。
- 水用清水即可（问助教要）；结束后擦干现场。

### 阶段 5：遥操作体验 + 收尾（2:30–3:00，时间不够可砍）

1. 每人轮流用主臂支架/VR 遥操作 5 分钟，感受夹爪开合、倾倒动作的可行性（VR 注意：双击 B 键接管/脱离，离开前确认机器人回零）。
2. 问助教问题清单（`06_questions_for_ta.md`）。
3. 收尾：机器人回打包姿态（机身降到最低）→ 关机 → 归还借用物品 → 清理水渍。

## 安全红线

- 机械臂/底盘动作时，所有人站在臂展（649 mm）+ 底盘活动范围之外；专人守急停。
- 机器人异响、发热、电量过低（<20%）立即停止。
- 洒水立即擦干，**严禁液体进入机器人本体**（倒液测试只在正式方案里做，今天不碰机器人倒液）。
- 打包/搬运时断电，抬机器人托底盘铁片、不抬外壳。

## 数据去向

脚本输出都在 `exp/day1/data/`（已加入 `.gitignore`，不入库）。回宿舍后：
- 照片给感知组（吕佳恒）做颜色识别与刻度标定；
- `01_dump_state.py` 的 JSON 给集成组核对 API 语义；
- 全部测量结果抄进仓库文档。
